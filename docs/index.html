All of these come from two maps the model never trained on. Pick one to compare its guesses with the units that are really there. The first 8 are the same sample this site has always shown. The other 15 were picked because the model gets them fully right, so they show what it can do, not how often it succeeds.

How it works

The training pictures were taken by the game itself: World Editor maps place random units or let computer players fight, take a screenshot and write down each unit's name and position. A YOLO26m model (Ultralytics) learned from them to find every unit and give it 48 scores, one for each type. It was exported to ONNX and runs here with onnxruntime-web.

How good it is

On 70 clean screenshots from a map it never trained on, it got 65 fully right (92.9%) and 180 of 183 units right. Those 70 were chosen before looking at its answers, with no unit stacked on another and none covered by a spell effect. On all 400 screenshots of that map it got 63.8% fully right, because units often stand on top of each other there. It has not been measured on real games yet, so expect more mistakes on those. Heroes and buildings are ignored on purpose.
